# oceanblossom.github.io

`https://oceanblossom.github.io` 도메인 루트. 실제 사이트는 [OCEANBLOSSOM/bokyung](https://github.com/OCEANBLOSSOM/bokyung) (`/bokyung/`).

이 저장소가 하는 일:
- 루트 접속을 `/bokyung/`으로 리다이렉트 (`index.html`)
- 도메인 루트 `robots.txt` (sitemap 위치 안내)
- 네이버 서치어드바이저 등록용 소유 확인 (네이버는 하위 경로가 아닌 호스트 단위로만 사이트를 등록함)
